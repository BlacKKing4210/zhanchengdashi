Tapping a locked plot directly attempts unlock if adjacent and affordable, otherwise shows the relevant short failure message; it never opens locked-building detail. Owned buildings still expose daily-function details.

- Generate original simplified consistent home building sprites: four types x eight fixed ring tiers, 32 distinct images. Ring1 is the simplest. The single initial castle retains its identity but receives a distinct home sprite; it has no level progression. No repeated/recolored substitute building images across tiers. Do not alter daily yield, ring prices, inventory or authoritative transactions for this visual tier.
- Buildings dominate owned plots, including ring1, larger than the previous 110px transparent canvas. Fit visible alpha bounds rather than whitespace; increase visible occupancy from tier1 to8 while staying inside the hex roads and keeping residents readable. Type/numerical information must not cover buildings.
- Every first-owned animal, all four rarities, must run rarity (tap or2s) then hero close-up. Diagnose normal gacha path without changing odds/grants or modifying real user ownership. Existing all-owned accounts are not to be reset or treated as new. Repeated animals do not trigger a false new-hero ceremony.
- Replace harsh draw/reveal audio with softer cues and a distinct warm surprise motif for new heroes. Avoid stacked high-frequency transients in ten-pulls. Verify event routing and provide actual audio evidence.
- Gacha result cards show card artwork/name/quality only, without level badges, fragment counts, upgrade progress or upgrade affordances. This change does not remove level information from deck or animal details.
