## 设计约束与核心决定

1. 当前一副牌固定八张；金矿和至少一张通用防御建筑占两位，因此动物构筑按六位设计。
2. 标准流派构筑采用“2 核心 + 2 重要 + 2 交叉”，但不设置凑标签即加属性的隐藏羁绊；流派由玩家可见的触发、效果和战术循环自然形成。
3. 将 v1 的八个概念收敛为六个主要流派：群潮推进、遗响接棒、护群反攻、疾行拓地、标记围猎、控制围歼；后勤和巨兽作为各流派可插拔的重要或交叉模块。
4. 每个流派分配十只主要归属动物：2 核心、4 重要、4 交叉。60 只动物必须且只能有一个主要归属；每只交叉动物必须声明一个不同的次流派及桥接作用。
5. 深度来自构筑替换、出手顺序、位置与目标选择、地图节奏、反制判断和跨流派转向，而不是来自不可见计数或大段规则文本。
6. 本次所有新数值、技能文本与解锁节奏均为设计候选；未经制作人批准和数据化平衡评审，不得进入 `config/tables/` 或 `runtime/config/`。

1. 六个流派必须各有独立的一句话幻想、核心循环、节奏窗口、弱点和可识别反制。
