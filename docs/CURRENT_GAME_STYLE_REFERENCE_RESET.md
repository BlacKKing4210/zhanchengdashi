# 占城大师 - 简化视觉风格参考初筛

> 状态：仅供风格方向审核，不是页面效果图，不是 UI/UE 定稿，不进入游戏实装。
>
> 本轮基线：忽略此前页面效果图；动物图片保持不变；用户确认风格后，才重新生成主页面效果图。

## 1. 本轮目标

- 明显降低视觉复杂度，让玩家先看懂动物、资源、战斗区域和主要操作。
- 保留当前白边动物图片，不重新设计动物。
- 选择一套能覆盖主页面、商店、编组、战斗、抽卡、更多和弹窗的统一视觉语言。
- 只借鉴公开参考中的构图、材质和信息层级原则，不复制商业游戏的角色、图标、布局或资产。

## 2. UIUX 流程筛选结论

本轮使用 `ui-ux-pro-max` 先做移动端风格与可读性筛选。自动设计系统曾给出 3D、超写实和粉紫配色建议，但与本项目的 2D、简单、保留动物要求冲突，因此明确淘汰。

保留的有效规则：

- 使用低复杂度 Flat Design / Flat Mobile 作为结构基线。
- 主色控制在 4-6 个，不使用渐变。
- 一个控件只允许一层边框；不再使用牌匾套牌匾、卡片套卡片。
- 阴影最多一层硬投影，也可以完全没有阴影。
- 移动端触控区域至少 48 x 48 px。
- 固定顶部资源栏和底部导航必须预留空间，不能遮挡页面内容。
- 正文与关键数字必须保持高对比；数字使用统一字号和稳定宽度。

## 3. 候选 A - 平面丝网印刷贴纸风（推荐）

### 参考来源

- [Dicey Dungeons 官方网站](https://diceydungeons.com/)
- [Dicey Dungeons - Nintendo 官方页面](https://www.nintendo.com/us/store/products/dicey-dungeons-switch/)
- [美国国会图书馆 WPA 海报馆藏](https://www.loc.gov/collections/works-progress-administration-posters/about-this-collection/)
- [WPA 国家公园海报缩略图](https://loc.gov/pictures/collection/wpapos/related/?co=wpapos&fi=ids&q=98518597%7C98518466%7C98518608%7C94502736%7C94502739%7C96503139%7C96503125&st=thumbnails)

### 可借鉴

- 候选 A 内部建议按 `70% WPA 平面印刷 + 30% Dicey Dungeons 欢快卡通` 组合，不复制具体布局或资产。
- 大块平涂色面、粗而稳定的深色轮廓、少量印刷错位感。
- 现有白边动物直接作为“贴纸主体”，不额外套复杂相框。
- 按钮采用完整色块、明确文字、单层墨线和最多一次硬偏移阴影；主要按钮只比普通按钮多一个强调色。
- 资源栏只显示图标与数字，数字在可用区域中严格居中，不重复写“金币”“券”等文字。
- 战斗区保持现有尺寸和单元格数量，只替换视觉资源。
- 背景以大色块和极轻纸纹分区，不画满树叶、帐篷、花朵和舞台装饰；套色错位只能用于背景插画，不能用于文字、数字和功能图标。

### 禁止项

- 多层金属包边、卷轴、帷幕、灯泡、徽章和嵌套牌匾。
- 渐变、柔光、玻璃质感、复杂高光和多层投影。
- 每个按钮都使用不同外形或不同装饰语言。

### 建议色板

`#24211D` 墨黑 / `#F7E6B5` 纸黄 / `#D9543D` 番茄红 / `#F2C14E` 向日葵黄 / `#2D8C7A` 青绿 / `#4E9BC4` 天蓝

### 适配判断

- 降低复杂度：5/5
- 兼容现有动物：5/5
- 全页面扩展性：5/5
- 主要风险：做得过平会显得普通，需要靠统一粗线、色块比例和排版建立辨识度。

## 4. 候选 B - 轻纸片舞台风（辅助方向）

### 参考来源

- [Paper Mario: The Origami King - Nintendo 官方页面](https://www.nintendo.com/en-gb/Games/Nintendo-Switch-games/Paper-Mario-The-Origami-King-1782440.html)

### 可借鉴

- 动物和建筑像贴在平面舞台上的纸片，天然兼容现有白边动物。
- 只用一层纸片错位或一层短硬投影表达层级。
- 战斗区域可以有非常轻的舞台边界，但尺寸、格子数量和操作位置不变。
- 弹窗像一张较厚的纸卡，背景只做单色压暗。

### 禁止项

- 纸张撕边、折痕、胶带、图钉、褶皱和多层剪纸同时出现。
- 把每个区域都做成立体舞台、纸盒或展开机关。
- 为追求纸张感降低文字和数字对比度。

### 建议色板

`#292521` 墨黑 / `#F5E9CF` 暖纸 / `#D95F47` 珊瑚红 / `#E6BA3B` 麦黄 / `#76A95B` 草绿 / `#5A97C8` 纸蓝

### 适配判断

- 降低复杂度：4/5
- 兼容现有动物：5/5
- 全页面扩展性：4/5
- 主要风险：纸张层级、投影和舞台装饰很容易再次堆复杂。

## 5. 候选 C - 手绘卡牌图鉴风（仅参考信息组织）

### 参考来源

- [Wildfrost 官方网站](https://www.wildfrostgame.com/)

### 可借鉴

- 卡牌中的名称、数值、状态和能力说明具有清晰的固定位置。
- 卡牌采用统一模板，变化集中在角色图和少量状态色。
- 商店、编组、抽卡和卡牌详情可以共用同一信息骨架。

### 禁止项

- 把所有页面内容都塞进卡牌。
- 模仿 Wildfrost 的角色、冰雪主题、卡框、图标或具体布局。
- 为每种卡牌增加不同外框、挂件、纹章和环境插画。

### 建议色板

`#2D2B36` 深墨 / `#FFF6DE` 奶白 / `#D96658` 暖红 / `#E7B643` 金黄 / `#77B88B` 薄荷绿 / `#6E9BC5` 柔蓝

### 适配判断

- 降低复杂度：3/5
- 兼容现有动物：3/5
- 全页面扩展性：4/5
- 主要风险：容易重新变成“卡片套卡片”，且原动物与参考角色画风不统一。

## 6. 产品负责人验收结论

推荐排序：

1. A 平面丝网印刷贴纸风：作为整套页面主方向。
2. B 轻纸片舞台风：只吸收单层纸片质感，不独立成为完整风格。
3. C 手绘卡牌图鉴风：只参考卡牌信息组织，不作为整体美术方向。

下一轮建议基线：`A 85% + B 15%`，C 只作为编组/卡牌详情的信息位置参考。

## 7. 统一复杂度红线

| 项目 | 上限 |
|---|---|
| 页面主色 | 不计算动物原图，单屏最多 6 色；单个组件最多 3 色；禁止渐变 |
| 单个控件边框 | 1 层 |
| 单个控件阴影 | 0-1 层；硬阴影或软阴影二选一；禁止内阴影、浮雕和外发光 |
| 同屏主要材质 | 1 种 |
| 纹理强度 | 页面背景 4%-6%；按钮和卡牌不超过 3%；文字、数字和功能图标为 0% |
| 字体层级 | 单屏最多 3 个字号层级；小字不使用手写体、描边或印刷错位 |
| 单屏主操作 | 1 个主 CTA |
| 页面装饰占比 | 不超过可视面积的 10% |
| 禁用装饰 | 角花、铆钉、灯泡、缎带、卷轴；装饰不得占用信息区域 |
| 顶部资源显示 | 图标 + 数字，数字居中，不重复资源名称 |
| 战斗区域 | 保持当前尺寸和单元格数量，仅换视觉资源 |
| 动物图片 | 完全保持当前版本 |
