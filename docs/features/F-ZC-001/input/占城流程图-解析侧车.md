## 2. 工作表“简图”

标题：游戏框架。

1. `ROGUE战斗`：作为前期引入玩法，从买量素材承接玩家。
2. `营地训练`：战斗后，建设自己的营地，并用英雄训练小兵。
3. `占城大师玩法`：用小兵和英雄和其他玩家 PK，实现 PVP 掠夺。

## 3. 工作表“流程图”

### 3.1 前期 ROGUE 流程

从左到右：

`开场剧情` → `选择区域` → `战斗（无打断）` → `解锁新区域` → `连续3选1` → `战斗（无打断）` → `战斗胜利获得资源`

参考截图表达：

- 区域选择、连续战斗、三选一强化与胜利资源结算构成前期 ROGUE 循环。
- 该段作为前期引入与资源来源，不是本次占城战斗内规则的直接复刻目标。

### 3.2 家园/领地准备流程

图中横向阅读关系为：

`战斗胜利获得资源` → `前往领地` → `经营领地` → `训练小兵` → `队伍编组`

随后由 `队伍编组` 进入占城对战匹配。

参考截图表达：

- 战斗后回到领地进行建设。
- 领地中的英雄承担训练小兵的职责。
- 玩家将训练完成的小兵编入后续占城对战队伍。

### 3.3 占城大师与多人扩展流程

从左到右：

`匹配对手` → `开始战斗` → `扩充领地` → `英雄登场` → `战胜敌方` → `掠夺资源` → `更大的世界` → `多人对战`

参考截图表达：

- 对战开始后，双方通过地块和兵营持续派兵，推动战线。
- 英雄在战斗中段或指定节点登场，形成明显战力跃迁。
- 胜利后从对手处获得资源，资源回到家园发展循环。
- 后期由单次 PVP 扩展到更大地图或多人/GVG 对抗。
